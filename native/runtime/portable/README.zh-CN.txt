Codex EVA v10.11 跨电脑安装包 / Windows x64

这就是跨电脑使用的包，自带独立 Python、Playwright 与 Node 驱动。
另一台电脑不需要原项目目录、原电脑的 Python 或开发环境。
适用于 Windows 10（19041及以上）/11 x64；不支持 macOS、Linux、ARM64。

使用方法
1. 在另一台电脑先安装官方 Windows 版 Codex，并完成正常登录。
   从EVA入口冷启动时自动将官方Codex外观设为“深色”，右上角原生窗口按钮随之变白。
   仅更新config.toml中的desktop.appearanceTheme，其余设置保留；不更改Windows系统主题。
   此偏好会保留。以后从原版入口启动时，可在Codex设置中自行改回。
2. 将整个 ZIP 解压到一个普通文件夹，不要在压缩包内直接运行。
3. 双击 Install.cmd。默认安装到 D:\Apps\CodexEVA；D 盘条件不满足时尝试 H 盘。
4. 安装成功后，从开始菜单打开 Codex EVA。
   也可以运行安装目录里的 CodexEVA.exe。
5. Esc 跳过片头；Ctrl+Alt+E 调整主题动效偏好。

自定义安装位置
在解压目录用 Windows PowerShell 执行：
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -TargetDirectory "E:\Apps\CodexEVA"
安装器不自动回退到 C 盘。按安装资源大小的3倍检查空闲空间，具体数值由 Check.cmd 显示；
不会把打包电脑的100/50 GiB磁盘保留规则用于其他电脑。保留 crosspc-2 的安装空间判断修复。
安装目录必须为空。已有版本可在正常退出Codex后将旧EVA目录移至备份位置，
或使用另一个空目录安装。本包不会自动覆盖或关闭正在运行的旧版本。
开始菜单已有的Codex EVA快捷方式若指向其他目录，会先备份到新安装目录。

只检查、不安装
双击 Check.cmd；检查完整性、依赖和本用户的Codex包，不启动Codex。
CheckOnly 模式会显示建议安装目录，已安装的同名目录不影响检查。

恢复与移除
安装目录中的“恢复原版.cmd”会请求移除当前EVA主题；随后正常退出Codex。
使用系统原有Codex入口启动即为原版。
移除时，退出Codex，删除本包的安装文件夹及“Codex EVA”开始菜单快捷方式即可。
若安装目录里有 previous-shortcut.lnk，可按需要恢复先前快捷方式。
请不要删除官方Codex安装和用户资料。

启动时的已有进程处理
- 健康的EVA主题实例直接唤起，不创建片头窗口，避免首帧一闪。
- 检测到没有可用EVA加载器的官方Codex进程时，先显示片头，再请求正常关闭旧进程。
- 等待5秒仍未退出，定向结束已校验包身份的旧Codex主进程，确认退出后重新启动。
- 因此从EVA入口接管原版或异常实例时会关闭其窗口；请先结束正在进行的工作。
- 不按进程名称批量结束，不关闭浏览器、独立ChatGPT应用或命令行codex工具。
